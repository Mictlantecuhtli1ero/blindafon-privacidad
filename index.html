Compromiso de privacidad

BLINDAFON está diseñada para ayudar a las personas a identificar contactos seguros y controlar llamadas no deseadas. El acceso a los contactos y al filtrado de llamadas se utiliza para proporcionar estas funciones.

1. Información que utiliza la aplicación

BLINDAFON necesita acceder a determinados datos del dispositivo para funcionar.

Contactos del teléfono:

La aplicación consulta los contactos guardados en el dispositivo para que el usuario pueda seleccionar cuáles considera seguros y reconocer sus llamadas.

La aplicación también declara permiso para guardar contactos, destinado a las funciones de administración de contactos.

Información de llamadas:

Cuando Android lo autoriza, BLINDAFON puede examinar información del número de una llamada entrante para aplicar las reglas de filtrado configuradas por el usuario.

2. Permisos de Android

BLINDAFON utiliza permisos y autorizaciones relacionados con las siguientes funciones:

  • Leer contactos: identificar números guardados y contactos considerados seguros.
  • Guardar contactos: permitir funciones de administración de contactos cuando estén disponibles.
  • Filtrado de llamadas: permitir que Android consulte las reglas de la aplicación al recibir determinadas llamadas.

El usuario puede revisar o modificar los permisos desde la configuración de Android.

3. Uso de la información

Los datos se utilizan para:

  • Mostrar y seleccionar contactos seguros.
  • Consultar las reglas de protección.
  • Identificar llamadas sujetas a filtrado.
  • Aplicar las preferencias de bloqueo.
  • Mostrar un registro local de llamadas rechazadas.

4. Almacenamiento local

La versión 1.3 utiliza almacenamiento local de Android para conservar preferencias de protección, selecciones de contactos y registros de llamadas rechazadas.

Los registros de rechazo pueden incluir número telefónico, fecha y motivo del bloqueo. El historial local está limitado a los registros más recientes según la configuración de la aplicación.

Estos datos forman parte del funcionamiento de la aplicación en el dispositivo.

5. Publicidad y utilización comercial

La versión 1.3 de BLINDAFON no incluye una función propia para vender agendas telefónicas ni utiliza los contactos para enviar publicidad.

Si futuras versiones incorporan servicios adicionales, publicidad, analítica o procesamiento remoto, esta política será actualizada para describir dichos tratamientos.

6. Servicios externos

BLINDAFON se distribuye mediante Google Play, que puede tratar información conforme a sus propias políticas y condiciones.

Puedes consultar la Política de Privacidad de Google .

7. Conservación y eliminación

Las preferencias y registros locales pueden permanecer almacenados mientras la aplicación conserve sus datos en el dispositivo.

El usuario puede eliminar los datos locales mediante las opciones de almacenamiento de Android. Esta operación puede borrar preferencias, listas configuradas y registros guardados.

8. Seguridad

BLINDAFON utiliza los mecanismos de permisos y almacenamiento proporcionados por Android.

No obstante, ningún sistema informático puede garantizar protección absoluta frente a todos los riesgos.

9. Limitaciones del filtrado

La capacidad de filtrar llamadas depende de los permisos concedidos, la versión de Android, el dispositivo y las restricciones del sistema.

Algunas llamadas legítimas de números no reconocidos podrían ser rechazadas cuando el usuario activa reglas restrictivas de protección.

Se recomienda revisar la lista de contactos seguros y comprobar cuidadosamente la configuración.

BLINDAFON no sustituye los servicios de emergencia ni garantiza la detección de todas las llamadas fraudulentas.

10. Privacidad de menores

BLINDAFON no está diseñada específicamente para niños. Los usuarios responsables deben revisar los permisos y las reglas de filtrado antes de utilizarla.

11. Cambios en esta política

El desarrollador puede actualizar esta política para reflejar cambios en las funciones de BLINDAFON, sus permisos o la normativa aplicable.

La fecha de actualización se indicará al inicio del documento.
